# clr91dev · Propuesta de icono v1

Icono de marca personal de Samuel, creado con la herramienta integrada ImageGen a partir de los iconos actuales de Trackle, Bezly y Zuvly y de la C de clr91dev.

Archivo: `clr91dev-icon-proposal-v1.png`.

La propuesta usa una C geométrica de esquinas redondeadas, azul muy oscuro, un pequeño acento turquesa y fondo marfil. El volumen es suave para relacionarla con Zuvly y conserva la simplicidad de Trackle y Bezly.

## Prompt utilizado

```text
Use case: logo-brand.
Asset type: a finished square personal-brand icon for Samuel's independent app studio clr91dev, suitable as a website favicon and social avatar.
Input images are style and identity references only, not edit targets: Image 1 Trackle supplies the quiet ivory/navy/turquoise palette and friendly rounded geometry; Image 2 Bezly supplies confidence, thick rounded forms and generous negative space; Image 3 Zuvly supplies a very restrained sense of material depth; Image 4 is the current clr91dev C-and-cursor mark and establishes the C identity.
Create ONE original final icon, not a contact sheet or brand presentation. Design a distinctive bold C monogram as a continuous softly squared ribbon with very rounded corners, open on the right, compact and beautifully balanced. The C should have the character of a carefully designed rounded-square app frame, but must clearly differ from Bezly's double-square icon. Add a single small turquoise rounded lozenge at the upper-right opening as an integral finishing accent, recalling the existing clr91dev pointer without drawing a literal mouse cursor. The icon should suggest making clear, thoughtful digital tools. No need to write the studio name.
Full-bleed warm ivory background close to #f5f4f0 across the entire square. Center the charcoal/deep blue-black monogram, occupying roughly 58 to 64 percent of the canvas width, with optically balanced generous margins. Turquoise accent close to #24bfa8; use it sparingly. Primarily clean graphic geometry with only extremely subtle satin edge highlights and low relief, almost flat, not a glossy 3D toy. The shape must read instantly at small sizes. Orthographic front view.
Constraints: a single icon only; no wordmark, no letters besides the single symbolic C, no 91, no caption, no watermark, no arrows, no code brackets, no extra UI, no mockup device, no surrounding tile or outer rounded-square border, no checkerboard, no long shadow, no decorative background gradient. Keep it polished, simple, personal, and coherent with the reference apps without copying their symbols.
```
